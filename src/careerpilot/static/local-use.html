本地使用与数据说明

Read in English

版本：local-use.v1 · 2026-10-26

仅本人本地使用

当前版本用于你在自己电脑上管理职业成长资料。默认服务只绑定本机回环地址。 本说明描述当前工程行为，不是面向公众的服务协议或经法务签核的隐私政策。 不向其他用户或未成年人提供服务，不应据此开放公网注册。

只导入你有权处理的资料，避免导入他人个人信息、凭据或未经许可的内容。 公开链接、星数和模型评语不等于内容许可或已验证能力。 本地申请演练不会联系雇主；实际投递仍由你在源站完成。

保存哪些资料

注册保存邮箱、昵称、密码盐和密码派生摘要；登录保存会话令牌摘要、设备说明和到期时间。 页面访问令牌只保留在内存中。邮箱当前仅作账号标识，不发送验证或找回邮件。

你提交的档案、JD、材料、目标、计划、测验、项目、简历版本、申请及复盘记录， 连同必要的来源、版本、授权和审计信息，保存在本地数据库中。 历史版本可能包含旧正文；删除源记录不一定删除已冻结的业务快照。

默认 Compose 使用本机 Docker 数据卷；旧宿主数据库与真实备份单独保留。 本地数据库不等于磁盘加密；能够访问电脑、Docker 或备份的人可能读取其中资料。

外部处理须另行授权

注册勾选不授予外部模型、公开网页访问或产品分析权限。你可以在设置中分别授权或撤销。 默认助手使用本地受控工具；配置模型密钥本身不会自动发送资料。 显式运行外部模型评测时，选定场景会发送给所选供应商，供应商处理和留存以其约定为准； 撤销本地授权不能删除供应商已收到的内容。

读取允许的公开网页或 GitHub 元数据会向相应站点发送请求；绑定 GitHub 是独立 OAuth 授权。 分享与日历导出须单独确认，当前本人使用无需启用分享。 未审核招聘、社交平台采集与真实自动投递继续关闭，多模型协作保持关闭。

保留、导出、撤销与删除

普通业务记录及其版本没有统一的自动到期日，保留至对应删除流程或账号注销。 主动导入来源与公开仓库元数据保留 30 天；媒体文字索引默认 7 天，可选 1–30 天； 面试录音默认 1 天，可选 1–7 天。到期后停止使用，Worker 清理相应记录和修订； Worker 停止时物理清理会延后。媒体原文件在临时处理结束后删除。

产品分析默认关闭，启用后仅保存限定事件，90 天清理；撤销时清除本人分析事件与修订。 请求指标不含请求正文，维护命令默认清理 30 天前指标；业务审计没有因此自动到期。

设置页可导出本人数据、撤销用途授权和管理登录会话。导出不包含密码派生摘要、会话令牌、 GitHub 密钥及分享票据。注销需输入 DELETE MY ACCOUNT；会话立即失效， Worker 随后清理在线库中本人数据。请保管一次性删除回执用于查询处理状态。

已下载的导出、他人已取得的副本、源站和外部供应商内容、离线备份不会因本机删除而自动消失。 恢复旧备份可能恢复旧授权和旧内容，恢复后应先离线核对并重新执行必要撤销或删除， 再启动会访问外部服务的任务。不要用删除 Docker 数据卷代替日常停止服务。

未来提供服务前

若以后要向他人提供、公开部署或处理未成年人资料，应先确定发布主体、面向地区、 处理者与数据流向，并完成相应协议、隐私政策、内容和依赖许可、未成年人规则与正式审核。 当前本地技术验收不代表这些正式发布条件已通过。

Personal local use

Version local-use.v1 · 2026-10-26. This build is for your own computer and personal use. The default server binds to loopback. This is an engineering disclosure, not public service terms or a legally approved privacy policy. Do not use it to open registration to others or provide a service to minors. Import only materials you may process, and avoid other people's personal information, credentials and unlicensed content. Public links, stars and model comments do not establish permission or verified skills. Application simulations do not contact employers; actual submission is your action on the source site.

Data and storage

Registration stores your email, display name, password salt and derived password hash. Sessions store token digests, device labels and expiry; the browser keeps its token in page memory. Email is an identifier only, without verification or recovery email. Profiles, jobs, materials, goals, plans, assessments, projects, resume versions, applications and reviews are stored with provenance, versions, consent and audit metadata. Old versions and frozen snapshots may retain old text after a source is deleted.

Compose uses a local Docker volume. Older host databases and business backups are separate. Local storage does not imply disk encryption. Anyone with access to your computer, Docker or backups may be able to read the data.

Optional external processing

Registration does not authorize external models, public web access or product analytics. Grant or withdraw these separately in Settings. The default assistant uses controlled local tools; configuring a model key does not automatically send data. Explicit external model evaluations send selected scenarios to the chosen provider under its own processing and retention terms. Withdrawing local consent cannot erase data already received by a provider.

Public web and GitHub metadata reads contact the corresponding sites. GitHub account binding uses separate OAuth consent. Sharing and calendar exports require their own confirmation; sharing is unnecessary for personal use. Unreviewed recruitment and social crawling, real automatic applications and multi-model collaboration remain disabled.

Retention and control

Ordinary business records and versions have no general automatic expiry; they remain until their deletion workflow or account deletion. Imported references and public repository metadata last 30 days. Media text indexes default to 7 days (range 1–30); interview audio defaults to 1 day (range 1–7). Expired content stops being used; the worker removes the corresponding records and revisions. Stopping the worker delays physical cleanup. Original media files are removed after temporary processing.

Analytics is off by default. Opted-in bounded events expire after 90 days; withdrawal removes your analytics events and revisions. Request metrics omit request bodies; the maintenance command defaults to removing metrics older than 30 days, without expiring business audits.

Settings provides personal data export, purpose withdrawal and session management. Exports omit password hashes, session tokens, GitHub secrets and sharing tickets. Account deletion requires DELETE MY ACCOUNT, revokes sessions immediately and queues worker cleanup of your online database records. Keep the one-time deletion receipt to check completion.

Downloaded exports, copies already obtained by others, source sites, external providers and offline backups are not automatically erased. Restoring a backup may restore old content and consent: review it offline and repeat needed withdrawals or deletions before enabling external tasks. Deleting a Docker data volume is not an ordinary stop operation.

Before serving others

Identify the publishing entity, regions, processors and data destinations, then complete applicable service terms, privacy policy, content and dependency licensing, rules for minors and formal review. Local technical acceptance does not approve public release.
