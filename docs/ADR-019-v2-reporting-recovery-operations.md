# ADR-019：可核对报表、可恢复复盘与公共运营

日期：2026-10-21。状态：本地实现；验收见 历史验证摘要（产物已清理）。

## 决定

1. 学习投入来自本人明确填写的 `study_log`，保留日期、分钟、记录时区、用途与撤回版本；同日总量不超过 1440 分钟。计划安排、完成任务和客观测验都不推定实际投入。报表区分本人记录、当前计划安排、首次完成任务、评估时间内新增证据与生成时能力状态，不冒充历史状态还原。
2. 求职漏斗以范围内创建的申请为同一队列，观察至范围末日或生成时的较早者。已提交只凭既有本人确认回执，面试/Offer 取该队列历史状态；重投是不同申请。每项转化同时给分子、分母，零分母为未知；当前收藏独立展示，不混作分母。未知时间和未核实提交保留未知。
3. 成长通知默认暂停，仅站内渠道。日学习、七日内截止核对、上完整自然周/上完整自然月报告分别开关，支持时区、静默、限频、暂停/取消。用户锁内原子保存通知与下一到期时间，失败事务不推进到期槽位。邮件传输未配置，拒绝当作可用渠道，不产生伪发送记录；原岗位订阅和申请提醒继续遵循各自配置。
4. `growth.review_pipeline` 是固定三步白名单：本期记录→来源引用→计划预览。每步独立事务、租约 fencing、结果与步骤进度一起提交。重试/人工介入/租约回收跳过已经提交的步骤；提交结果后、任务确认前重启不会重复生成预览。档案/证据/岗位/计划变化阻止继续使用旧上下文；取消失效租约。结果是草案/预览，接受仍由用户另行决定。
5. 可选公开读取沿已有用途同意、来源审查、DNS/TLS 与大小限制。流程只持久化链接/读取时间/指纹和源记录 ID，摘录存可删除的 30 天来源库，私人来源不复制正文到流程历史；来源删除或到期后不从流程副本复活内容。
6. 公共技能、职业、资源、模板、岗位分类使用 `CatalogueEntry` 的主版本、独立变更单与只追加历史。提交者不能自己审核，管理员才能发布；回滚也是基于当前版本的新审核单。发布前重验规范、技能/别名与先修 DAG、规范 URL、带时区的核对时间及凭据扫描；旧依赖直写 HTTP 入口改为只校验并引导审核，避免绕过治理。公共字段不得包含私人材料。
7. 工单属于本人私有聚合。同租户运营只看类别、公共资源 ID、状态等元数据，不能读取详情、私人岗位或附件；只能保存状态和给本人的反馈。跨个人空间的原文共享未启用。成本、失败、拒绝访问审计与来源告警只返回聚合指标；没有模型质量评测时不填造准确率。待执行模型调用不计作错误或完成延迟。

## 存储与取舍

新增私人聚合复用账号导出/注销和备份；公共治理记录复用公共目录，不混入私人表。无需新增表、迁移或依赖。已发布公共版本保留公共运维历史；本轮没有对外发布网站、发送邮件或实际招聘提交。

当前统计按用户明确记录和本地岗位库运行，不能衡量真实招聘结果。通知限频只覆盖本页成长通知，其他提醒配置单列。复盘是受控三步工作流，不宣称任意 Agent 任务或不可逆外部动作的 exactly-once。运营元数据不足时只能要求本人核对，跨账号人工支持仍不启用。
