# ADR-018：可归属的来源库与受限平台回退

日期：2026-10-21。状态：V2 第五批本地实现；验证见 历史验证摘要（产物已清理）。

## 决定

- 新增私人 `source_document` 聚合，复用 GrowthRecord/Revision、所有权、账号导出/删除与备份，无新增表/依赖。链接、短摘录、作者、发布日期、本人标签、技能、授权范围与导入/实际读取时间分别保存；来源时间未知就保留未知。最长 30 天，到期读取失效，Worker 每分钟清除主库记录与全部修订。本人可用版本条件即时删除；只留无内容审计。
- 发现按关键词、岗位/技能交集、类型和平台筛选公共登记入口及本人来源；返回明确模式、检索时间及未执行外部搜索提示。项目代码、文档、社区和视频入口区分展示；不执行 README、不绑定账户、不自动形成技能/经历/项目验证。
- 手动链接只做 HTTPS 引用规范化，不解析 DNS 或访问；去除查询/跟踪参数，禁止凭据、非标准端口和 IP 字面地址。内容纯文本/凭据扫描；用户确认有权在私人空间处理，选择仅链接或本地摘录。本人标注“官方”仍是待核实陈述。
- 交叉比较只处理用户明确标注的主题、值及原文跨度。不同值保留全部出处并标冲突，相同值仍未验证；同域名或不同域名都不能保证来源独立。比较瞬时计算不另存内容副本，删除后不能继续通过比较端点取回。
- GitHub 只读公开仓库元数据使用独立已登记的 `github_metadata` 范围；原 `github` 私有/通用适配仍关闭。访问需 public_web 授权；固定 api.github.com、公开 DNS 固定、TLS、无跳转、128KiB 上限和 socket 超时，无认证信息。全局来源行锁在网络前持久化一次尝试，间隔 120 秒，失败退避 30 分钟；失败不伪造结果。保存前复核授权和审查有效性。字段白名单不含个人资料/README/代码。
- 小红书/抖音 A 搜索索引和 C 授权 API 未配置，feature flag 关闭；B 用户主动导入可用。界面和 API 均不声称直接搜索、抓取或转写，无登录/验证码/私有接口路径。来源接入登记见 [技术范围记录](source-review-v2.md)。

## 取舍

登记索引不是实时全网搜索；比较是显式标注的字符串差异检查，不是语义事实核验。星数、平台许可证标记和官方入口不能代表资料质量、内容授权或本人能力。移除查询参数可能让部分分享链接需要本人重新提供规范链接；不自动访问以猜测原文。

公开元数据配额也受同出口其他应用影响，失败时提供本地索引和手动导入。保留清理目前扫描来源聚合，适合本地数据量；大规模部署应增加可索引的到期字段与批次维护。在线删除不瞬间改写历史备份，按备份保留制度处理。
