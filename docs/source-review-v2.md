GitHub 官方文档明确公开资源可在无身份认证下调用该只读接口，见 [接口范围](https://docs.github.com/en/rest/repos/repos#get-a-repository)。未认证配额按源 IP 计，通常每小时 60 次，见 [限频说明](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)。本应用进一步限制为全局每两分钟一次尝试，不能保证共享出口中其他应用不消耗配额；收到拒绝/限流即退避，不轮换令牌规避限制。[API 条款](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#h-api-terms) 禁止滥用及通过 API 收集数据用于垃圾信息等用途；本适配器不读取用户资料、联系人或招募名单。

日期为本次技术审查时间。`seed.py` 只新增独立的 `github_metadata` 范围，不覆盖已有停用或改动的登记；仍通过既有有效期/范围/用途授权闸口。公开元数据中的许可证标记不能替代实际复用许可审计，星数不等于资源质量，README 不验证个人能力。
