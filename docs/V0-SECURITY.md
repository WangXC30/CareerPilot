# V0 数据、安全与接入基线

范围为个人本地开发与工程验证。公网部署沿 V4 正式审核，不由本文件批准。

| 数据等级 | 例子 | 处理 |
| --- | --- | --- |
| 凭据 | 会话令牌、模型/API 密钥 | 随机会话令牌仅存摘要；外部密钥由只读 secret 文件注入；需要持久化时用 SecretVault，密钥与密文分离；禁止日志/前端回显 |
| 私人资料 | 简历、对话、证据、目标 | tenant/user 双重过滤；运营/管理员没有默认私人读取权；外部模型每次调用前和结果发布前检查可撤销 consent |
| 运营元数据 | 状态、错误枚举、重试、计数 | 运营角色可读，禁止包含原始提示词、简历、异常消息或密钥 |
| 来源内容 | 用户导入、以后授权的第三方片段 | 独立 access_basis/scope/限频/保留期/审核截止；未经审核不能激活；第三方当前均关闭 |

认证：高熵 `cpk_` 令牌默认 24 小时，由本地 CLI 发放，撤销即时生效；角色通过服务端 RoleGrant 查询，不能从请求 body/模型输出授予。V1 账户功能不由该开发 CLI 代替。正式部署必须另行评审 TLS、正式认证和密钥托管。

SecretVault 使用 Fernet 认证加密，`CAREERPILOT_VAULT_KEY_FILE` 指向容器内只读文件。密钥不进入源码、镜像、数据库或 API 响应。当前没有真实外部 provider 凭据，也不会自动生成或发送私人资料。需要接入时由运维挂载 secret，并记录处理者、用途与同意，不能把通用开发授权当成个人资料授权。

上传扫描仅接受 UTF-8 文本与大小限制、凭据模式、NUL 和 EICAR 拒绝；**这不是通用杀毒引擎**，二进制文档、PDF 和 Office 上传仍默认不支持，不能放宽后声称已完成病毒扫描。扫描接口不持久化原文。外部文本即使通过扫描，也始终标记 untrusted_data。

工具风险由服务端不可变 ToolSpec 定义：R0/R1 仅许可范围内自动读取/草拟；R2/R3 需动作、目标、内容 hash、用户、有效期相符的单次审批，原子消费；超时/次数/Schema 超限拒绝。V0 不注册对外发送工具，注入文本无法创建工具或改变授权。

URL 安全原语拒绝非 HTTPS、白名单外 Host、用户信息/特殊端口、私网与元数据地址。后续真正的抓取适配器必须固定已校验连接 IP，并逐次校验重定向；**当前没有通用抓取实现**，禁止只调用一次 DNS 校验后用普通客户端抓取，以免 DNS 重绑定。

来源台账由 `python -m careerpilot.seed` 幂等初始化。唯一可用来源 `user_import` 仅代表用户主动提交、当地处理，不含对外检索/再分发许可。GitHub、招聘平台、小红书、抖音保持禁用；启用前必须更新有效审核、允许操作和保留策略，并经测试确认。

审计保留最小 actor/time/reason/revision/trace，reason 是私有字段，运营只看枚举/聚合。请求指标仅记录路由模板、状态、耗时和 trace；不用 URL 参数或请求/响应 body。单机开发指标由本地数据库保存，日常清理保留 30 天；正式留存政策在 ADR-010 确认。
