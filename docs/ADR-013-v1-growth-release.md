# ADR-013：V1 本地职业成长闭环

日期：2026-10-20（Asia/Shanghai）。决策：完成 V1 本地功能版，继续沿用 Compose、FastAPI、SQLAlchemy、SQLite/PG 合同与现有页面。

## 领域与运行边界

1. 本地邮箱/密码注册登录：密码使用随机盐与 scrypt，随机会话仅存摘要，认证限流；
   注册保存隐私同意，外部模型和公开来源同意分开控制。邮箱当前作为账号标识，不声称已验证邮箱所有权。
2. 0004 增加账户凭据/认证窗口/删除请求、版本化公共词库、追加式技能证据与独立撤销表。
   私有证据使用用户/租户复合外键；原始材料、计划和历史仍使用 V1 已有聚合与快照，领域 API 负责字段和状态校验。
3. 注销先撤销所有会话，独立 Worker 在事务中清理所有拥有用户/租户列的私有表及用户；
   删除回执凭随机秘密查询，完成后清除请求中的用户/租户关联。离线备份按原保留流程处理，不声称随在线注销自动消失。
4. 学习词库当前覆盖软件基础方向：8 个标准技能、4 个职业路径、12 项六种类型资源。
   职责为有来源的编辑整理，先修/学习成本为本地学习路径配置；不冒充中国岗位市场统计或官方资格要求。
5. 技能证据只追加；撤销单独记录，失败、通过、学习完成、自述分开保留。基础测验仅验证题目/rubric 覆盖的基础知识，
   不代表完整技能或岗位胜任力。默认有效期 90 天，状态计算保留规则版本和时间；过期/撤销不能授予 verified。
6. 计划先生成草案再发布。确定性程序检查周预算、截止日期、任务 DAG、先修覆盖、资源和验收定义；
   发布还检查档案、目标、岗位、词库与证据上下文。任务操作、考核和目标/预算变化生成事务内重排预览。
7. 自动重排保护锁定/已完成任务及其先修链，保留原任务内容；目标切换不会因为某技能有一段锁定任务就丢弃剩余学习量。
   接受预览检查版本/证据指纹，拒绝保持活跃计划，历史恢复仍遵守当前预算/目标/保护约束。
8. 主助手使用一个有租约的 Worker，默认本地意图路由与 Schema 工具白名单；工具调用复用相同领域规则。
   写操作只生成草案/预览，不替用户发布或接受。外部发送与投递工具没有接入白名单；高风险审批原语沿用 V0。
9. 网页工具只检索登记的官方资源索引；实际网页读取需要单独同意，逐跳校验允许主机、公开地址、TLS 证书并固定连接 IP，
   限时限长，仅生成文本短摘录与 URL/时间/摘要。错误不伪装为成功，也不据此关闭岗位。任意网页内容没有工具权限。
10. JD 抽取为可复现规则和原文跨度；小金标包含合成边界样例和一份真实岗位短摘录。
    这不是大规模市场准确率或真实模型质量承诺。无需外部付费模型即可执行本批闭环。

## 验证、替代与取舍

接受当前小词库、文本材料、官方来源索引和客观基础题库的可复现闭环，保持 schema/版本与来源接口以便扩展。
不为 V1 引入外部登录供应商、付费搜索、全网采集或代码执行；它们需要相应来源/预算或 V3 沙箱能力。
材料格式支持 txt/md/json；复杂格式转换、通用语义模型和更大独立金标是后续扩展，而非当前格式/质量承诺。

验证与边界见 [V1 出口](V1-EXIT.md)。V1 E2E-05 验证客观测验失败，原代码测试子场景仍在 V3；
E2E-06 在 V1 验证技能证据、差距和计划重评，V2 再验证岗位匹配分项。

## 升级、回滚和权限

开发卷升级前快照：`backups/pre-v1-release-0004-20261020.db`；先停 API/Worker，再备份、迁移和启动。
本轮测试仅使用独立临时库/Compose 项目，主开发库没有发放合成验收账号。0004 降级会删除本次六个新表，
不可在仍需 V1 数据的库上直接降级。恢复快照需匹配源码、迁移和凭据版本，恢复后重新验证权限与业务数据。

本轮授权为完成 V1，未扩展到 V2–V4、公网部署、发邮件、投递或替用户签收。
