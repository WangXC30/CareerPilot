# ADR-022：多岗位技能交集与先修图

日期：2026-10-22。范围：CP-143 / FR-SKL-005、FR-SKL-006。

- 只读 POST `/api/v1/skill-graph` 接受 3 至 20 个不同的本人岗位，重复 ID 去重；跨用户记录返回 404，关闭/合并岗位拒绝参与。无写库、外部请求或新增迁移。
- 统计只取所选 JD 的已收录、明确必需/优先技能，不混入主职业百科。重复提及只保留多段原文，不增加岗位频次。全部岗位出现为共同，部分（至少两个）为交叉，一个为特有；没有已识别技能的 JD 仍计入分母。仅提及和否定要求不计入；规则抽取范围和未知项明确展示。
- 先校验整个词库 DAG，再按拓扑顺序投影技能与完整先修闭包。先修节点不增加 JD 频次；每条边从先修指向后续技能。图是编辑整理的学习关系，不冒充行业必然规则。
- 返回岗位/词库版本、原文位置与引用、当前 foundation 能力状态、资源可用性及测验方式。能力状态读取现有台账；查看图谱不改变能力、计划或学习记录。
- 页面以 SVG 展示方向，以原生 details 提供键盘可操作的逐节点详情。大图在独立区域横向滚动，窄屏不撑开整页。选择变化清空旧图，异步结果须匹配页面与选择版本。岗位标题及引用统一转义，页面不展示原始 JSON。
- 数据是请求时的快照，重新生成读取最新版本。资源为登记来源，不宣称实时连通；当前固定词库有限，未识别不等于不存在要求。

验证见 历史验证摘要（产物已清理）。本批不将图谱入口视作 CP-154 学习模式/间隔复习完成，也不代验 GitHub OAuth。
