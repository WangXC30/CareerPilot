# ADR-017：文字练习、确认复盘与受信项目回执消费合同

日期：2026-10-21。状态：第四批本地实现，验证见 历史验证摘要（产物已清理）。

## 决定

1. 文字练习固定本人 JD、不可变简历版本及最多三条已确认项目/经历陈述。基础题来自已版本化客观题库；项目、场景、行为题附引用，项目/场景回答各可追加一次带原回答引用的追问。未知知识点保持开放题，不制造标准答案。
2. 会话与问答保存为私有 GrowthRecord/Revision；所有权、用户事务锁、If-Match 和创建幂等控制并发。答题接口及其历史不返回参考答案；完成后的不可变评价才展示客观答案。中断可恢复，主动结束不会生成完整评价。
3. 正确性仅评分基础选择题。完整性是四类结构标记的可追溯原文跨度，表达是长度代理指标；开放题技术正确性与陈述真实性仍未知。项目分项仅引用当前有效受信回执。评价不写 SkillEvidence，不自动更新事实、记忆或能力状态。
4. 原评价不可编辑；本人可另存、修订或撤回有版本历史的复盘。复习项只能关联本场已收录知识点。生成预览保留原任务，保护已完成/锁定及先修闭包，检查预算、先修与截止日；用户接受时再原子修改计划。复盘改版/撤回、上下文或计划变化使待接受预览失效。已接受任务留在计划中，需另行调整。
5. 新增聚合复用账号导出/删除及备份；SQLite 与 PostgreSQL 使用相同合同，无新增迁移或依赖。练习是有界同步规则计算，不冒充多步骤 Agent 恢复或外部模型评价。

## 项目证据边界

`project_evidence.py` 只是关闭默认信任的消费适配器，没有上传/确认即可变为项目通过的 API。仅消费 scope=project、kind=assessment_result 的最新技能记录；失败、撤销、过期和来源失效均不能回退到旧通过记录。验收记录须属于本人、版本一致、evaluator/rubric 受信且通过，并绑定已提交制品的版本、SHA-256 内容指纹和技能。基础知识快照明确仅消费 foundation 范围，项目失败不覆盖基础测验。

项目验收生产端属于 V3 CP-161/162/180/181，当前没有接入。正向合同测试采用明确标记的受信生产端模拟，不是实际执行项目测试。材料、README、简历、自述或面试回答均不产生项目验证；开发库缺少受信回执时项目分项保持未知。CP-190 保持开发中，CP-191 保留依赖出口。

## 取舍

当前本地题库窄、追问为固定规则，代理指标可被堆词或长度影响，不能推断招聘结果或真实能力。后续扩展语义评价需独立数据和质量验证，语音/笔试属后续阶段。当前交付只验收 CP-230/231 的上述本地范围，不提前计完整 V2 或质量任务包。
