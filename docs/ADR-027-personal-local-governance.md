# ADR-027：本人本地使用的治理边界

日期：2026-10-26（Asia/Shanghai）。用户在本轮明确说明“仅本人本地使用”。

## 决定

继续沿既有本地工程范围完成 CP-262，交付本人使用告知、可撤销用途授权、来源审核失效拒绝、账号导出与删除及依赖审计。任务的原始正式上线定义继续保留；本地技术结项不构成实际发布主体的法律签核，也不代表面向公众、未成年人或跨境处理的正式审核通过。今后改变使用范围时，重新执行正式发布评审。

当前实例由本人控制，默认只绑定回环地址。没有建立对外服务主体或对公众作出服务承诺，不虚构客服联系方式、地域合规结论、法务负责人或签字。注册时已有的 `privacy_policy.v1` 同意记录仅表示私人资料存储确认，不追认成正式协议签署，不改写历史记录。

## 本地使用告知

`src/careerpilot/static/local-use.html` 是随应用交付的中英说明，注册提交前和页面页脚均可打开。它说明资料与历史版本、本地数据库和备份、密码/会话摘要、各类内容的实际期限、Worker 清理延迟、用途撤销、导出和注销，以及外部处理的独立授权。该文件是持续维护的产品说明，不是临时测试报告或验收清单。

恢复旧备份可能重新引入旧授权和已删除内容；应先离线核对，必要时重做撤销/删除，再运行会访问外部服务的任务。源材料删除与不可变业务快照删除、在线库清理与离线备份清理分别说明，不承诺所有副本即时消失。普通业务记录和审计没有统一自动到期，不将维护命令的 30 天指标清理写成全库留存规则。

## 来源审核的工程约束

权限必须是有限、无重复、格式有效的字符串数组；JSON 字符串、对象、混合类型、无效或过深 JSON 不授予任何权限。只按完整操作名称匹配，拒绝子串和对象字段匹配。启用值必须为 1，审核者与接入依据不能仅为空白；审核过期、限频或保留期未设置时拒绝。来源运营视图对异常权限展示空列表，保留排查入口，不因 JSON 解析错误导致整页不可用。启用失败事务不提交，幂等种子不续期或覆盖停用决定。

未经审核的 GitHub 原始适配器、招聘平台、小红书与抖音采集继续关闭。公开仓库元数据仅沿原单独授权范围；用户导入不会授予抓取或再分发许可。申请功能仍采用本人源站提交与断网演练，多模型协作保持 No-Go。

## 依赖处理

本轮审计发现 certifi 与 pypdf 的已知漏洞，因此更新精确锁版本至 certifi 2026.10.19 和 pypdf 6.21.2，并提高项目的 pypdf 最低版本。版本与修复信息核对 [certifi 的官方发行页](https://pypi.org/project/certifi/2026.10.19/) 和 [pypdf 官方变更记录](https://pypdf.readthedocs.io/en/6.21.2/meta/CHANGELOG.html)。许可证通知继续随发行包保留；主工程未被擅自指定开源许可证，也未据此获得对外分发批准。

依赖审计失败时，在同一临时上下文输出包名、漏洞编号与修复版本，再清理详细清单并非零退出。审计失败不再只输出无法定位问题的计数。测试、截图、音视频、导出样本和审计报告仍只允许在系统临时目录内短暂生成；真实业务数据、业务备份与用户配置按原规则保留。
