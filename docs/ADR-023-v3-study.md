# ADR-023：学习节奏、间隔复习与个人资源反馈

日期：2026-10-22。范围：CP-154 / FR-LRN-006、007、008。

## 决定

1. 模式是当前计划的版本化设置。冲刺/均衡/科研繁忙/低负担分别使用档案可用周预算的 100%/75%/50%/25%（向下取整，最低一分钟），不修改档案上限。冲刺在依赖可执行的任务中优先岗位覆盖，均衡保留顺序，繁忙/低负担优先短任务。超预算任务拆段并保持依赖；总工作分钟不删减，以调整每周负担和完成日期体现模式差异。
2. 模式变更生成 `plan_preview`，绑定计划版本及既有上下文。接受才写计划，拒绝不写；锁定/完成任务和先修闭包保持原样，进行中/跳过任务同样保留。与固定任务、截止日或先修冲突时展示错误并禁止接受。所有计划验证取档案上限与计划模式预算的较小值；后续重排、项目与面试追加任务遵守模式预算。历史恢复仍为用户明确确认的版本操作。
3. 复习队列读取本人未撤销的 foundation 客观测验历史。连续通过的不同本地日期对应 1/3/7/14/30 天，失败重置为一天，同日重复通过不延长。最新测验提供错题解释与重测入口，逾期仅表示计划日期已过，不给出伪精确遗忘概率。历史证据到期不删除复习需求，系统异常/项目评测不进入本队列；复习页面不直接写能力证据。
4. `spaced_review` 加入现有站内通知设置，默认关闭，沿用用户时区、每日上限、静默时段、所有权锁和投递去重。没有到期条目不发空通知。关闭后不再排程，既有通知保留历史；独立于每日任务提醒。没有邮件/外部渠道。
5. 资源收藏、质量评价、坏链举报及说明保存在本人 `resource_feedback`，使用 CAS 与历史；不直接修改公共资源事实。公共 `/catalogue/resource` 继续返回纯公共目录供运营审核；个人 `/learning-resources` 返回覆盖后的资源，避免把私有字段混入公共提案。相同网址的重复目录项一并避开。取消举报可恢复；公共目录原不可用状态保留。计划、图谱、资料发现、搜索及助手资源结果使用同一个个人覆盖层。
6. 本技能没有可用外部资源时提供明确标注的本地测验/错题入口，不宣称是等价课程或实时联网替换。反馈说明沿用文本扫描，允许导出/随账号删除；没有外部抓取或自动传播私人反馈。

复用 GrowthRecord/Revision 与 schema 0004，无新增迁移或依赖。验证见 历史验证摘要（产物已清理）。GitHub 时间线/OAuth 仍为 CP-113 后续范围。
