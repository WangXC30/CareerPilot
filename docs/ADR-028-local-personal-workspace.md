# ADR-028：免登录的单人本地工作区

日期：2026-10-26。状态：已实施，取代当前产品的账号登录与运营角色流程。

用户明确项目是本人使用的本地个性化工具，不需要登录、注册或运营权限。所有业务资料继续保存在本机；是否使用外部模型或来源是单独配置和授权，不因打开应用自动启用。

## 决策

- 正常启动采用单个个人工作区，无邮箱、密码、访问令牌、登录会话或运营角色入口。前端打开时自动读取本地工作区，刷新和重启继续访问同一份资料。
- 迁移 0006 只新增 `local_workspace` 关联表。首次空库建立内部资料归属；已有唯一历史资料时沿用原 user_id/tenant_id，不复制事实、重建空账号或改写版本。内部归属字段保持来源、证据、任务和历史关联，不是用户需要管理的账号。
- 多份历史资料不能自动猜选或合并：返回明确错误并保持全部原记录。当前真实库经只读核对只有一份个人资料，已直接沿用。
- 默认 API 不提供 `/auth/*`、`/admin/*`、会话管理或公共词库运营修改接口；已有角色授权记录不会被默认运行时读取，旧管理员令牌不能改变本地工作区归属。
- 本地端口仍只发布到回环地址；API 检查 Host、Origin 和浏览器跨站标记，防止其他网站借免登录入口读取或修改资料。保持确定性业务规则、来源验证、模型预算、外部处理开关及重要操作确认。
- “我的资料与设置”提供资料编辑、导出、用途开关和“清空本地资料”。清空须输入 `CLEAR LOCAL DATA`；处理中停止原工作区写入，Worker 完成清理后自动建立新的空工作区。真实离线备份不会随清空而删除。

## 兼容与验证

历史账号、凭据和角色表不作为当前产品功能，但暂保留数据库兼容和历史合同测试；不在这次变更中破坏旧备份。`create_app(..., local_only=False)` 只用于明确标记的历史回归夹具，普通 Uvicorn/Compose 启动没有切换到它的配置。历史浏览器夹具由测试传输层注入合成身份，不再操作不存在的登录弹窗。

新增工作区测试覆盖免凭据访问、重启持久化、唯一旧资料沿用、无新令牌/角色记录、运营/认证接口不可用、跨来源拒绝、并发首次打开、歧义保护及清空后重新开始。原领域所有权与幂等测试继续作为内部数据完整性回归；不将其解释为当前产品提供多用户平台。

实际数据库升级前已建立本地业务快照并校验完整性；迁移后原 10 条成长记录和 2 个目标保持，API/Worker 正常启动。真实业务备份保留，测试数据库、截图及验证产物仅临时使用。具体命令结果记录在 PLAN W-053，不在本文保留测试日志或报告。

后续实现沿用免登录产品语义，不能重新变成用户账号、注册或运营权限流程。2026-10-27 补充：用户已取消 Electron，确认 React 网页和 Docker Compose 部署，见 [ADR-029](ADR-029-web-stack-docker.md)；原桌面进程握手/IPC 设想不再适用，本地 Host/Origin/跨站访问约束仍保留。
